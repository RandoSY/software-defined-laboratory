Start a laboratory session
Hardware: DS18B20 ↔ MSP430 P1.7; MSP430 UART ↔ Pico GP0/GP1; optional P2.0 marker ↔ Pico GP2; Pico USB ↔ Chrome. Share ground and use 3.3 V logic only.

1. Upload protocol.py, labcore.py, and main.py to Pico W running MicroPython. Program the separate MSP430 acquisition application through its debug interface.

2. Close Thonny and any serial monitor using the Pico USB port. Open this file in current Chrome. Click Connect USB and select the Pico serial device.

3. Measure the actual room temperature with another thermometer, enter it as ambient, choose the sample period, and click Apply settings then Start.

4. Use the Precision graph tab for the full-resolution cooling curve, elapsed-time windows, °C scaling, crosshair, and model/residual overlays. Under Experiment control, press Mark experiment event whenever you stir, insulate, or otherwise change conditions. See instrument errors and fit statistics under LINC instrument.

5. Use Record to file for ongoing on-disk CSV recording, or Export CSV at the end to download the complete current browser session.

The original 1-Wire transport and newly integrated MSP430 application are hardware-validation candidates. Do not use this educational system for safety-critical temperature control.
Offline simulation and teaching notes

A clearly marked synthetic cooling run allows exploration of the dashboard without hardware. The synthetic model shown is a demo stand-in for the data normally computed by the Pico; it is never presented as physical measurement.

Teaching questions: What is a sampling interval? Why do we preserve invalid evidence? Why does a DS18B20 take up to 750 ms to convert? What can a Pico timestamp establish, and what can it not establish? Can the Pico detect a temperature threshold even while the browser is disconnected? Why does a fixed ambient temperature affect the inferred cooling constant?

Newton's cooling: T(t) = Ta + (T0 − Ta) exp(−kt). The Pico uses a log-linear fit for the valid measurements where T − Ta is sufficiently positive.

Architecture boundary: MSP430 owns the 1-Wire bus. Pico owns experimental operations, scientific fitting and volatile sample memory. Browser owns graphics, user administration and the persistent CSV file.
