HOW A RUN WORKS

From setup to review

  1. 01
    Describe

    Name the run, set the recording interval, and note the setup.

  2. 02
    Record

    Linux timestamps each status snapshot and stores it in the local archive.

  3. 03
    Review

    Stop the run, then open Archive to download a CSV for analysis.

✦

Synthetic readings are labeled in the run and CSV. Live sensor readings require the firmware to already be in live mode.
